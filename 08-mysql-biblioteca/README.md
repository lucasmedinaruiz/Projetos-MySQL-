# mysql-biblioteca

Projeto de banco de dados MySQL para iniciantes, com tema fictício (livros, leitores e empréstimos).

## Conceitos praticados
- `CREATE DATABASE` e `CREATE TABLE`
- Tipos de dados, `PRIMARY KEY`, `AUTO_INCREMENT`, `NOT NULL`
- `FOREIGN KEY` (relacionamento entre tabelas)
- `INSERT`, `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`
- `JOIN`, `UPDATE` e `DELETE`

## Como executar
Abra o MySQL Workbench (ou o terminal) e rode o arquivo `biblioteca.sql`:
```
mysql -u root -p < biblioteca.sql
```
